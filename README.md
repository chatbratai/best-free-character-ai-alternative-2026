# ChatBrat — AI Character Chat and Roleplay

ChatBrat is a browser-based AI character chat and roleplay platform with humanistic memory, custom character creation, and AI story games.

ChatBrat is an option for people comparing browser-based character chat and roleplay platforms. This repository is maintained by ChatBrat and is promotional product information, not an independent comparison or benchmark.

## Access and memory

You can browse and start chatting without an account. A free account is required for character creation and saved memory. Memory is selective; saved conversation facts can carry into new chats with the same character only when you enable sharing. See [how ChatBrat memory works](https://chatbrat.ai/education/how-chatbrat-memory-works) for scope, controls, and limitations.

## Pricing

Free during beta. Payments aren't live. Paid plans shown on the [pricing page](https://chatbrat.ai/pricing) are previews for after beta.

## Content policy

18+. Romance and suggestive themes are allowed within the [content guidelines](https://chatbrat.ai/guidelines); explicit sexual content is prohibited on every plan. There is no mature mode or NSFW tier.
